# Logos oficiales de categoría

Coloca aquí el logo oficial de cada categoría (SVG o PNG con fondo
transparente, a ser posible) con el nombre en minúsculas, sin espacios
ni símbolos, igual al slug normalizado:

- f1.svg              → Fórmula 1
- wec.svg              → WEC
- gtworldchallenge.svg (o gtwc.svg) → GT World Challenge
- imsa.svg             → IMSA
- dtm.svg              → DTM
- indycar.svg          → IndyCar
- wrc.svg              → WRC
- nascar.svg           → NASCAR
- motogp.svg           → MotoGP
- gt.svg               → GT

Mientras no exista el archivo de una categoría, la web sigue mostrando
el monograma genérico (el cuadrado negro/naranja) como fallback — no
rompe nada subir los logos poco a poco.

Este README no se sube a producción como contenido (es solo una nota
para el repo); Astro lo servirá como archivo estático si no se borra,
pero no pasa nada.
